# P00 Visual Audit: jurassicenglish.com (production, read-only)

Date: 2026-10-15. Method: Playwright 1.49 driving cached Chromium headless-shell (rev 1208). 12 pages: full-page screenshots at 320/375/768/1024/1440/1920 for EN, 375/1440 for VI (56 captures), plus targeted viewport captures. For every page and width I measured horizontal overflow, elements extending past the viewport, text clipped by overflow:hidden, fixed widgets covering links/buttons (scroll sweep plus elementFromPoint check), images with naturalWidth 0, heading order, tap targets under 24px, loaded webfonts (`document.fonts`) and text contrast. I looked at the 375 and 1440 captures myself. Nothing was edited, deployed or submitted.

Scratch dir: `/private/tmp/claude-501/-Users-jayadams-Downloads-World-Wide-Learning-WWL-Website-Design-2026-WEBSITE-OVERHAUL-DIRECTIVE/3d1b1974-0f33-4b4a-8141-46238d9939e5/scratchpad/p00-visual/` (below: `$S`). Raw metrics: `$S/results.json`, `$S/contrast.json`.

**Passes measured on every page and width:** HTTP 200; `scrollWidth == innerWidth` (no horizontal page scroll); 0 broken images; 0 images without alt; exactly one H1; Vietnamese diacritics render with correct stacking (see VI-1 for the typeface issue). The only clipped text found was intentional `sr-only` content.

**False positives removed:** nav-link contrast "2.18" (the oklab header background broke the parser; actual is forest #1E4D3B on cream); "1.00" on white H1s over dark gradients (no solid background to resolve); `p` font-size of 12px on home and baseline (that was the first `<p>`, an eyebrow, not body copy); the sticky header showing mid-page in the 1440 young-learners full-page capture (a capture artifact; checked with viewport shots).
